# Sprint 01 - Application Foundation & Shell

Duration: 2 Days

Status: ✅ Complete

Goal

Build the single-root application shell, navigation system, and responsive layout.

---

## Features

- **Single-Root Directory Structure**: Angular application located directly at repository root.
- **Application Shell**: Header, Sidebar Navigation, Sidenav Container, and Footer.
- **Responsive Layout**: Breakpoint Observer integration for mobile and desktop views.
- **Routing Setup**: Route definitions for Dashboard, Expenses, Categories, Reports, and Settings.

---

## Key Components

- `HeaderComponent` (`src/app/layout/header/header.component.ts`)
- `SidebarComponent` (`src/app/layout/sidebar/sidebar.component.ts`)
- `FooterComponent` (`src/app/layout/footer/footer.component.ts`)
- `PageContainerComponent` (`src/app/layout/page-container/page-container.component.ts`)

---

## Deliverables

- ✅ Working application shell with navigation between all feature views
- ✅ Responsive drawer sidenav
- ✅ Angular Standalone Component architecture setup
