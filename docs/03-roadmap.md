# Product Roadmap

**Project Name:** Fincz Expense Tracker

**Version:** 0.1.0

**Status:** Active

**Author:** Kaunain Ahmad

---

# Overview

This roadmap defines the planned development phases of the project.

Each version focuses on a small set of features that can be completed, tested, and released independently.

The goal is to build the application incrementally while maintaining production-quality code.

---

# Development Strategy

Each release should include:

- New Features
- Bug Fixes
- Documentation Updates
- Unit Tests (where applicable)
- Screenshots
- Release Notes

# Success Criteria

The project will be considered successful when:

- It is used as the primary personal expense tracker.
- It becomes part of the Fincz ecosystem.
- It demonstrates production-level Angular and Spring Boot development.
- It serves as a strong portfolio project for recruiters and clients.
