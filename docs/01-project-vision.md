# Overview

Fincz Expense Tracker is an open-source personal finance application.

The goal is to build a simple, fast, and modern expense tracker that anyone can use to manage daily expenses.

This project also serves as a learning project for modern software development using Angular and Spring Boot.

---

# Problem Statement

Many expense tracker applications have one or more of these problems:

- Too many premium features
- Limited customization
- Closed source
- Difficult to extend
- No investment tracking
- No developer documentation

This project aims to solve these problems by building a clean and extensible application.

---
